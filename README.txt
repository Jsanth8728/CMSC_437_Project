Project Description:
This project provides an in-flight entertainment system for the Last Choice
Airlines passengers. The following features are available on each of the pages:

HOME SCREEN
The home screen displays information about the airline, a custom logo, and 
the following user preferences:
    - Preferred language
    - Volume level
    - Subtitle settings
    - Favorite movies
    - Dark Mode
    - Seat preferences
    - Notifications
    - Playback preferences

These preferences persist if a user is logged in and get saved.

CONTENT AND MEDIA PlAYBACK 
This screen shows a multitude of movies, tv shows, music, and attractions 
(specifically ones that are for where the flight is headed). There is a favorites
section that a user can update by clicking on the favorite button. It can
be removed by clicking the remove button. These save as long as a user is logged
in as well. Recommendations would populate the more a user flew and the system
gained knowledge of the types of media they enjoyed watching/listening to. 

FLIGHT INFO 
The flight information page shows the flight path from start to destination. It
also displays the ETA, current altitude, current speed, local time, and destination
time. 

SHOPPING
This page shows toys, clothing, merchandise, and airplane memorabilia all for sale.
If a user clicks on the item, they can either add it to their card or choose back 
if they wish to keep browsing. Users can see what is displayed in their cart by 
clicking on the cart icon. They can remove items right from the cart and click "Buy
Now" to buy their items.

FOOD AND DRINKS
This page shows appetizers, entrees, snacks, and drinks all for sale.
If a user clicks on the item, they can either add it to their card or choose back 
if they wish to keep browsing. Users can see what is displayed in their cart by 
clicking on the cart icon. They can remove items right from the cart and click "Buy
Now" to buy their items.

PHONE
On this page, a user can place a call with the key pad provided. If they click call,
the call will be placed in their shopping cart so they can view their invoice (shown
in the shopping cart).

HELP
The help page shows announcements made during the flight. It also displays safety
information for the plane. If they click "call attendant," it will bring a flight
attendant to their seat. Lastly, they can choose "Feedback" and enter Feedback
for the infotainment system.

ANNOUNCEMENTS BAR
The announcements bar can be clicked on to display:
    - announcements made throughout the flight
    - Login page

LOGIN PAGE 
By clicking the log in page, they can either log in to their existing account
or continue as a guest. If they continue as a guest, preferrences and movies will
not be saved. 

AI USAGE
Gemini was used to create the Last Choice Airways logo with the prompt "make me 
a logo for a fake airline called last choice airways to put on my homepage."
